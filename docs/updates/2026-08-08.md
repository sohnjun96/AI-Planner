## 23:27 - 일정 모달 바깥 클릭 판정 개선

### 변경 요약

- 일정 추가·수정 모달 안에서 시작한 드래그를 바깥에서 끝내도 모달이 닫히지 않도록 수정했다.
- 주 포인터의 왼쪽 버튼 누르기와 놓기가 모두 백드롭에서 발생한 경우에만 모달을 닫도록 판정을 강화했다.

### 주요 영향 파일

- `src/components/TaskModal.tsx`
- `dist/assets/app.js`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- 브라우저에서 일정 수정 모달 내부에서 바깥으로 드래그한 뒤 모달이 유지되고, 백드롭 클릭 시에는 닫히는지 확인

### 주의사항

- 새 외부 패키지나 권한 변경은 없으며, 일정 추가·수정 공용 모달에 동일하게 적용된다.
