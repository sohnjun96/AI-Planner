- 기존 기능 테스트를 다크 환경에서도 실행하고, 테마별 미리보기 배경·검색 빈 상태·버튼 높이 차이·빈 문서 및 자동분류 fixture를 실제 화면 동작에 맞춰 검증하도록 보완했다.

### 주의사항

- 기존 사용자 변경·데이터·원색·API 동작·권한·CSP·DB 스키마·앱 버전은 유지했다. 실사용 프로필·실제 API 없이 합성 데이터와 모의 응답만 사용했다.
- 색상 대비는 alpha·조상 opacity·그라데이션 정지점과 premultiplied-alpha 보간을 고려했다. 비활성 컨트롤·숨겨진 요소·장식은 별도 제외했다. 기준: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- 단일 HTML 원문 편집기의 기존 CodeMirror 동적 스타일/CSP 배치 문제는 남아 있다. 다크 글자색을 검증했으며 이 문제 해결을 위해 보안 정책을 완화하지 않았다.
- 검색 회귀에서 잡힌 본문 요청은 기존 노트 자동분류 요청이었다. 분류 완료한 합성 fixture로 검색과 분류 검증을 분리했으며, 검색 요청에 원본 본문·기록 식별자가 없다는 검사를 유지했다.
