## 누적 변경 요약

### 보안 및 안정성 강화

- `dist`와 원본 소스를 함께 검토하고 입력 검증, 응답 크기 제한, 요청 타임아웃, 동시 요청 제한, 가져오기 용량·건수 제한을 적용했다.
- API 키가 앱 DB, JSON 내보내기, 자동 백업에 포함되지 않도록 분리했다.
- Chrome 확장 프로그램 권한과 CSP를 MOIP 호스트에 필요한 최소 범위로 제한했다.
- 의존성 버전을 고정하고 빌드 시 기존 `dist`를 복구용으로 보존하는 원자적 교체 절차를 적용했다.

### AI 연결 설정

- LLM 엔드포인트를 `https://llm.moip.go.kr/api/chat/completions`로 고정했다.
- API 키는 입력이 멈춘 뒤 Chrome 확장 저장소에 자동 저장하고, 저장 직후 다시 읽어 검증하도록 변경했다.
- 최신 입력만 순서대로 저장하도록 디바운스와 저장 큐를 적용했다.
- API 키를 메모리와 Chrome 저장소에서 즉시 삭제할 수 있는 기능을 유지했다.
- AI 설정 화면에서 불필요하게 긴 엔드포인트 안내 문구를 제거했다.
