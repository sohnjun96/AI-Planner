## 16:19 - 내부망 모델 목록 호환성과 점심 메이트 AI 복구 개선

### 변경 요약

- 내부망 모델 목록을 OpenAI 호환 `/v1/models`에서 먼저 조회하고, 서버 경로 차이가 있으면 `/api/v1/models`, `/api/models` 순서로 조회하도록 개선했다.
- OpenAI 호환 `data` 배열은 엄격히 검증하되 프록시가 `Content-Type`을 누락한 정상 JSON 응답도 처리하며, 401·403·429 오류는 원인별 안내를 제공한다.
- 점심 메이트 AI 요청이 화면 데이터 갱신으로 취소되지 않도록 실행 수명 주기를 분리하고, 실패 상태 표시와 수동 재시도 버튼을 추가했다.
- 기존 실패 캐시가 새 실행을 막지 않도록 캐시 키를 갱신하고, 현재 설정 모델이 서버 목록에 없을 때 선택 변경 안내를 표시한다.

### 주요 영향 파일

- `config/build-profiles.json`
- `scripts/build-profile-config.mjs`
- `scripts/build-extension.mjs`
- `scripts/run-tests.mjs`
- `src/agent/llmClient.ts`
- `src/pages/ArchivePage.tsx`
- `src/pages/SettingsPage.tsx`
- `tests/llmClient.compat.test.ts`
- `dist/assets/app.js`
- `docs/BUILD_PROFILES.md`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:external`
- `npm run build:internal`
- `npm audit --audit-level=low` (취약점 0건)
- 내부·외부 번들의 Endpoint 포함 및 반대 망 주소 미포함 확인

### 주의사항

- 모델 목록 대체 조회는 빌드 시 승인된 동일 HTTPS 출처의 최대 3개 경로로 제한하며, 사용자가 임의 주소를 주입할 수 없다.
- 모델 목록은 전체 요청 시간 15초, 응답 256KB, 모델 500개 제한을 유지하고 API 키나 서버 원문을 저장·기록하지 않는다.
- 점심 메이트 자동 정리는 하루 1회만 실행하며, 실패 시 사용자가 명시적으로 누른 경우에만 추가 재시도한다.

## 16:45 - 점심 메이트 비스트리밍 요청의 조기 취소 수정

### 변경 요약

- 점심 메이트처럼 JSON 응답 전체를 기다리는 비스트리밍 AI 요청에 15초 유휴 제한이 적용되어 정상 응답 전에 취소되던 문제를 수정했다.
- 비스트리밍 요청은 60초 전체 제한 안에서 응답을 기다리고, 스트리밍 요청만 기존 15초 유휴 제한을 유지하도록 분리했다.
- 브라우저의 원시 `signal is aborted without reason` 오류 대신 사용자 취소와 시간 초과를 구분한 안내를 반환한다.

### 주요 영향 파일

- `src/agent/llmClient.ts`
- `tests/llmClient.compat.test.ts`
- `dist/assets/app.js`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:external`
- `npm run build:internal`
- `npm audit --audit-level=low`

### 주의사항

- 요청 제한을 제거하지 않고 비스트리밍은 최대 60초, 스트리밍 무응답은 최대 15초로 제한한다.
- 취소 오류에는 API 키, 요청 본문 또는 서버 응답 원문을 포함하지 않는다.

## 17:04 - 점심 메이트 AI 요청 스트리밍 전환

### 변경 요약

- 점심 메이트 AI 정리를 `stream: true` SSE 요청으로 전환해 모델 생성 중 수신되는 데이터로 유휴 시간을 갱신한다.
- 스트리밍 토큰은 화면에 노출하지 않고 내부에서 제한된 크기로 합친 뒤 기존 JSON 검증 절차를 적용한다.
- SSE의 `[DONE]`을 정상 완료로 처리하고, 비스트리밍 요청은 JSON만 수락하도록 `Accept` 헤더를 요청 방식별로 분리했다.
- 프롬프트 입력 필드를 `candidates: [{ name, count }]`로 명확히 정의했다.

### 주요 영향 파일

- `src/agent/lunchMateAgent.ts`
- `src/agent/llmClient.ts`
- `tests/llmClient.compat.test.ts`
- `dist/assets/app.js`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:external`
- `npm run build:internal`
- `npm audit --audit-level=low`

### 주의사항

- 스트리밍도 전체 60초·무응답 15초·응답 1MB 제한과 동시 요청 최대 2개 제한을 유지한다.
- 테스트는 가상 SSE 응답으로 URL, 메서드, 스트리밍 본문, `[DONE]` 처리와 최종 별칭 JSON 검증을 확인하며 실제 키를 사용하지 않는다.
