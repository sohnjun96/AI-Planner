# 2026-08-06 업데이트

## 16:19 - 내부망 모델 목록 호환성과 점심 메이트 AI 복구 개선

### 변경 요약

- 내부망 모델 목록을 OpenAI 호환 `/v1/models`에서 먼저 조회하고, 서버 경로 차이가 있으면 `/api/v1/models`, `/api/models` 순서로 조회하도록 개선했다.
- OpenAI 호환 `data` 배열은 엄격히 검증하되 프록시가 `Content-Type`을 누락한 정상 JSON 응답도 처리하며, 401·403·429 오류는 원인별 안내를 제공한다.
- 점심 메이트 AI 요청이 화면 데이터 갱신으로 취소되지 않도록 실행 수명 주기를 분리하고, 실패 상태 표시와 수동 재시도 버튼을 추가했다.
- 기존 실패 캐시가 새 실행을 막지 않도록 캐시 키를 갱신하고, 현재 설정 모델이 서버 목록에 없을 때 선택 변경 안내를 표시한다.

### 주의사항

- 모델 목록 대체 조회는 빌드 시 승인된 동일 HTTPS 출처의 최대 3개 경로로 제한하며, 사용자가 임의 주소를 주입할 수 없다.
- 모델 목록은 전체 요청 시간 15초, 응답 256KB, 모델 500개 제한을 유지하고 API 키나 서버 원문을 저장·기록하지 않는다.
- 점심 메이트 자동 정리는 하루 1회만 실행하며, 실패 시 사용자가 명시적으로 누른 경우에만 추가 재시도한다.
