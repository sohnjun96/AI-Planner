## 09:03 - 최신 화면 개선 및 루틴 알림 배포 패키지 갱신

### 변경 요약

- 프로젝트 색상으로 구분하는 압축형 루틴 카드, 관리 버튼 가시성 개선과 모든 화면의 루틴 일정 생성 알림을 배포 패키지에 반영했다.
- 설정 아이콘, AI 일정 추가·브리핑 배치와 연결 실패 안내 등 현재 앱 변경 사항을 소스·검증 스크립트 및 전날 변경 이력과 함께 커밋한다.
- 내부망 확장용 `dist.zip`과 단일 HTML용 `dist-web/planai.zip`을 최신 소스로 재생성했다.

### 주요 영향 파일

- `src/components/RoutineList.tsx`, `src/pages/RoutinesPage.tsx`, `src/pages/RoutinesPage.css`
- `src/components/RoutineReminder.tsx`, `src/components/AppReminderStack.tsx`, `src/components/AppReminderStack.css`
- `src/components/AppShell.tsx`, `src/components/DailyBriefing.tsx`, `src/pages/DashboardPage.tsx`, `src/index.css`
- `package.json`, `scripts/test-routines-ui.mjs`, `scripts/test-routine-notifications.mjs`, `docs/updates/2026-09-22.md`
- `dist/assets/app.js`, `dist/assets/app.css`, `dist.zip`, `dist-web/planai.html`, `dist-web/planai.zip`

### 검증

- `npm run build`, `npm run build:single-html`: 타입 검사, 내부망 확장 빌드 및 단일 HTML 무결성 검사 통과.
- `npm run lint`, `npm test`, `npm run test:routines`, `git diff --check` 통과.
- ZIP을 다시 읽어 CRC32와 각 파일의 SHA-256을 확인했다. 확장 ZIP 10개 파일과 단일 HTML ZIP 1개 파일이 원본과 일치한다.
- 확장 ZIP 최상위에 `manifest.json`과 `index.html`이 포함되어 압축 해제 후 확장 프로그램으로 로드할 수 있음을 확인했다.

### 주의사항

- 앱 버전은 1.3.0을 유지하며 데이터 스키마와 네트워크 권한은 변경하지 않는다.
- 내부망 배포 설정을 사용한다. 설치된 확장은 압축을 해제한 최신 `dist` 내용으로 다시 로드해야 적용된다.
