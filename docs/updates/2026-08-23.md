## 01:48 - 라이브 노트 편집기 전면 재구성

### 변경 요약

- 앞서 적용한 편집 DOM 치환 장식 방식을 폐기하고 Lexical 기반의 Markdown 편집 코어로 라이브 노트 편집기를 전면 교체했다. 제목·본문·굵게·기울임·취소선·하이라이트·인라인 코드·인용·목록·체크리스트·표·구분선·코드 블록을 서식이 적용된 화면에서 직접 편집할 수 있다.
- 라이브/원문 모드를 하나의 편집 세션 안으로 통합하고, 모드별 컴포넌트 교체와 상위의 별도 Undo 스택을 제거했다. AI 제안과 버전 비교를 열어도 편집기 인스턴스가 제거되지 않는다.
- 한글 IME 조합 중에는 부모 초안과 자동 저장으로 중간 조합 문자열을 전달하지 않고, 조합 완료 뒤 확정된 Markdown을 한 번만 반영한다. 편집기가 전달한 값을 다시 편집기에 주입하는 제어형 피드백 루프도 제거했다.
- 라이브 파서가 처리하지 못하는 이미지·원시 HTML·기타 미지원 구문은 내용을 비우지 않고 원문 안전 편집 화면으로 전환하며, 구문을 수정한 뒤 라이브 편집을 다시 시도할 수 있다.
- 이미지, 노트 링크, 백링크, 링크·노트 자동완성, 슬래시 자동완성은 포함하지 않았다. 외부 링크는 `http`, `https`, `mailto`만 허용하고 자동 링크 변환과 HTML 처리를 비활성화했다.
- AI 편집 요청에 노트 ID와 로컬 편집 revision을 결합해 다른 노트로 이동했거나 응답 대기 중 본문이 바뀐 경우 오래된 제안을 적용하지 않는다. 라이브 선택 영역은 원문 위치가 하나로 확정될 때만 인라인 AI 편집 대상으로 전달한다.
- 자동 저장 스냅샷을 정규화하고 저장 진행 건수를 카운트해 겹친 저장의 상태 표시가 먼저 끝난 요청 때문에 풀리지 않게 했다. 메타데이터 변경 직후의 초안을 동기 반영하고, 선택 노트 체크 토글이 미저장 본문을 덮지 않게 했다.
- 삭제 전에 해당 노트의 저장 큐와 AI 요청을 정리하고, DB 쓰기 트랜잭션 안에서 노트 존재를 다시 확인해 삭제된 노트가 오래된 저장으로 되살아나는 경로를 막았다. 버전 복원은 노트 갱신과 복원 버전 기록을 하나의 트랜잭션으로 묶었다.
- 자동 제목은 오래된 전체 노트 스냅샷을 저장하지 않고 `updatedAt`이 일치할 때 제목 필드만 갱신한다. 자동 저장 버전의 최초 시각을 보존해 장시간 편집해도 새 체크포인트가 계속 생성될 수 있게 했다.

- 페이지 스크롤 후에도 푸터 하단 위치가 유지되는 것을 확인
