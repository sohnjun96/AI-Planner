## 18:45 - 기존 JSON 백업의 공용 메모 호환 복원

### 변경 요약

- 기존 확장 프로그램 백업에 포함되는 공용 메모 식별값 `date: "global"`을 버전 4·5 가져오기에서 정상 허용하도록 수정했다.
- 대시보드 공용 메모 저장도 같은 검증 규칙을 사용하도록 통합해 저장 직후 발생하던 날짜 형식 오류를 제거했다.
- 일반 메모 날짜는 실제 달력에 존재하는 `YYYY-MM-DD`만 허용해 잘못된 날짜가 저장되거나 복원되지 않도록 강화했다.
- 내부망·외부망 확장 프로그램과 단일 HTML 배포본을 모두 다시 빌드했다.

### 주의사항

- 호환 예외는 앱이 기존부터 사용해 온 정확한 공용 메모 키 `global`에만 적용되며 임의 문자열은 계속 거부한다.
- JSON 가져오기는 현재 데이터를 교체하므로 실제 복원 전 자동 백업 목록 또는 별도 JSON 파일을 보존하는 것이 안전하다.
