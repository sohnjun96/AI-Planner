## 13:12 - AI 일정 추가의 현재 시각을 한국 시간으로 명시

### 변경 요약

- AI 일정 추가 요청의 `now`를 UTC의 `04:10Z` 대신 같은 순간인 한국 시간 `13:10+09:00` 형식으로 전달한다.
- `timeZone: Asia/Seoul`을 함께 전달하고, 이미 한국 시간으로 변환된 값에 9시간을 다시 더하지 않도록 AI 지침을 명시했다.
- 확장 프로그램과 단일 HTML·ZIP 배포 파일을 갱신했다.

### 주요 영향 파일

- `src/utils/date.ts`, `src/agent/scheduleAgent.ts`
- `tests/scheduleTime.test.ts`, `scripts/run-tests.mjs`
- `dist/assets/app.js`, `dist-web/planai.html`, `dist-web/planai.zip`

### 검증

- `npm test`: 10개 테스트 묶음 통과. 13:10 변환, 한국 자정·연말 날짜 전환, 변환 전후 동일 순간 및 실제 요청 본문의 시간대 필드를 모의 응답으로 검증했다.
- `npm run lint`, `npm run build`, `npm run build:single-html` 통과(타입 검사 포함).
- ZIP 내부 HTML이 배포 HTML과 동일한지 확인했다.

### 주의사항

- 기존 저장용 UTC 시간과 DB 스키마, 버전은 유지한다. AI 일정 추가의 현재 시각 표현만 변경했다.
- 실서버 AI 호출 및 기존 일정 데이터 변경은 수행하지 않았다. 확장 프로그램과 앱 페이지를 새로고침하거나 갱신된 단일 HTML을 다시 열어 적용한다.

## 13:46 - 내비게이션 정리 및 화면별 추가 버튼 배치

### 변경 요약

- 상단에 대시보드·나의 루틴·노트·프로젝트·나의 기록 메뉴와 질문·설정 아이콘만 표시한다.
- 상단의 AI 일정 추가 버튼을 대시보드 본문으로 옮기고, 노트·루틴은 각 화면의 기존 추가 버튼을 사용한다.
- 도움말 버튼은 설정 화면으로 옮겼으며 기존 도움말·노트 추가·AI 일정 추가 단축키를 유지했다.
- 모바일 하단 메뉴를 5열로 조정하고 질문과 설정을 상단에서 사용할 수 있게 했다. 설정의 활성 상태와 접근성 이름을 제공한다.
- 확장 번들 및 단일 HTML·ZIP을 갱신했다.

### 주요 영향 파일

- `src/components/AppShell.tsx`, `src/pages/DashboardPage.tsx`, `src/pages/SettingsPage.tsx`, `src/index.css`
- `dist/assets/app.js`, `dist/assets/app.css`, `dist-web/planai.html`, `dist-web/planai.zip`

### 검증

- 린트, 확장 및 단일 HTML 빌드(타입 검사 포함), 소스 공백 검사 통과.
- 독립 Chromium에서 5개 메뉴, 설정 활성 표시, 도움말, 질문 및 일정·노트·루틴 추가 동작 확인.
- PC와 모바일 390px·320px 화면 캡처 검토 및 가로 넘침 검사 통과. 외부 요청은 차단하고 가상 노트만 사용했다.

### 주의사항

- 데이터 스키마, 권한, 버전 변경 없음. 기존 저장 데이터와 단축키 동작을 유지한다.
- 질문 기능은 기존 모달을 유지하며 풀페이지 질문 기능은 이번 작업에 포함하지 않았다.
