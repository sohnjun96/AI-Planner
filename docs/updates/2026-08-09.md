## 00:19 - 프로젝트 색상 팔레트 개편

### 변경 요약

- 프로젝트와 일정 종류에서 선택할 수 있는 색상 프리셋을 중복도가 낮은 20색 팔레트로 교체했다.
- 20개 프리셋이 10개씩 두 줄로 정렬되도록 선택 그리드를 조정했다.
- 새 프로젝트와 랜덤 색상 선택에는 새 팔레트를 사용하며, 기존 프로젝트와 일정 종류에 저장된 색상값은 변경하지 않는다.

### 주요 영향 파일

- `src/constants.ts`
- `src/index.css`
- `dist/assets/app.js`
- `dist/assets/app.css`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`

### 주의사항

- 기존 데이터에 대한 색상 마이그레이션은 수행하지 않으므로 기존 항목은 이전 색상을 계속 표시한다.
- 외부 패키지, 권한, 데이터 저장 형식은 변경하지 않는다.
