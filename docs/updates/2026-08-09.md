## 00:19 - 프로젝트 색상 팔레트 개편

### 변경 요약

- 프로젝트와 일정 종류에서 선택할 수 있는 색상 프리셋을 중복도가 낮은 20색 팔레트로 교체했다.
- 20개 프리셋이 10개씩 두 줄로 정렬되도록 선택 그리드를 조정했다.
- 새 프로젝트와 랜덤 색상 선택에는 새 팔레트를 사용하며, 기존 프로젝트와 일정 종류에 저장된 색상값은 변경하지 않는다.

### 주요 영향 파일

- `src/constants.ts`
- `src/index.css`
- `dist/assets/app.js`
- `dist/assets/app.css`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`

### 주의사항

- 기존 데이터에 대한 색상 마이그레이션은 수행하지 않으므로 기존 항목은 이전 색상을 계속 표시한다.
- 외부 패키지, 권한, 데이터 저장 형식은 변경하지 않는다.

## 10:41 - 대시보드 주간 보기 이동 기능 추가

### 변경 요약

- 주간 보기 상단에 `이전 주`, `이번 주`, `다음 주` 버튼을 추가했다.

- 현재 주간을 보고 있을 때는 `이번 주` 버튼을 비활성화하고, 좁은 화면에서는 이동 버튼이 별도 줄로 배치되도록 했다.

### 주요 영향 파일

- `src/pages/DashboardPage.tsx`
- `src/pages/DashboardPage.weekNavigation.css`
- `dist/assets/app.js`
- `dist/assets/app.css`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- 브라우저에서 이전 주·다음 주 이동 시 시작일이 7일씩 변경되고 `이번 주` 복귀가 동작하는지 확인

### 주의사항

- 기존 주 시작 요일 설정을 그대로 따르며 외부 패키지, 권한, 저장 데이터 형식은 변경하지 않는다.

## 10:48 - 일정 시간 선택 UI 개선

### 변경 요약

- 일정 추가·수정 폼의 브라우저 기본 시간 입력을 시·분 선택 UI로 교체했다.
- 12시간제에서는 오전·오후, 시, 분을 분리하고 24시간제에서는 시와 분을 분리해 표시한다.
- 분 선택지는 5분 간격으로 제한하되 기존 일정이 다른 분 값을 사용하는 경우 원래 값을 별도 선택지로 보존한다.
- 종료 시간에는 선택값을 한 번에 제거할 수 있는 `비우기` 버튼을 추가했다.

- `src/components/TaskForm.tsx`
- `src/components/TimeSelect.tsx`
- `src/components/TaskForm.timeSelect.css`
- `dist/assets/app.js`
- `dist/assets/app.css`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- `git diff --check`
- 브라우저에서 24시간제와 12시간제 표시, 오전·오후 전환, 5분 간격 분 선택 및 미리보기 반영 확인

### 보안·호환성 관련 주의사항

- 외부 패키지·네트워크 요청·권한을 추가하지 않았으며 기존 일정의 비정형 분 값을 임의로 반올림하거나 유실하지 않는다.

## 10:51 - 종료 일시 일괄 지우기 추가

### 변경 요약

- 고급 옵션의 종료 날짜 입력 옆에 `지우기` 버튼을 추가했다.

- `npm test`
- `npm run build:internal`
- `npm run build:external`
- `git diff --check`
- 브라우저에서 종료 날짜와 `14:35`를 입력한 뒤 `지우기`를 눌러 날짜·시·분이 모두 초기화되는지 확인

### 보안·호환성 관련 주의사항
