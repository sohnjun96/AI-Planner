## 21:40 - 일요일 기본 주간 및 AI 모델 목록 선택

### 변경 요약

- 새 설정과 주 시작 값이 없는 가져오기 데이터의 기본 요일을 일요일로 변경하고, 주간 통계도 선택한 시작 요일을 따르도록 했다. 사용자가 저장한 월요일 선택은 유지한다.
- AI 설정에서 승인된 MOIP 호스트의 OpenAI 호환 `GET /v1/models`를 사용해 모델 목록을 불러오고 선택할 수 있도록 했다.
- 목록 조회가 실패하거나 결과가 없더라도 모델 식별자를 직접 입력할 수 있으며, 입력값은 저장 전에 검증한다.

### 주요 영향 파일

- `src/constants.ts`
- `src/context/AppDataContext.tsx`
- `src/utils/importBackup.ts`
- `src/agent/llmClient.ts`
- `src/pages/SettingsPage.tsx`
- `dist/assets/app.js`
- `docs/updates/2026-08-05.md`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm run build`
- `npm audit --audit-level=low` (취약점 0건)
- `git diff --check`

### 주의사항

- 모델 조회 요청은 승인된 HTTPS 호스트로만 보내고 API 키를 응답·오류·변경 이력에 기록하지 않는다.
- 모델 목록은 15초 타임아웃, 256KB 응답 한도, 최대 500개 제한을 적용하며 화면 이탈이나 인증 설정 변경 시 요청을 취소한다.
- 기존 사용자가 명시적으로 저장한 월요일 설정은 데이터 무결성을 위해 자동 변경하지 않는다.
