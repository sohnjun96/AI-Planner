## 12:58 - 단일 HTML 실행 오류 및 무결성 검증 개선

### 변경 요약

- 생성 후 내용이 달라진 단일 HTML의 CSP 해시가 실제 인라인 JavaScript·CSS와 불일치해 빈 화면이 되던 문제를 정상 재빌드로 복구했다.
- 단일 HTML 빌드가 최종 저장 파일의 CSP 해시를 다시 계산해 검증하도록 하고, 기존 산출물만 검사하는 `verify:single-html` 명령을 추가했다.
- 설정 화면의 버전은 별도 `manifest.json` 요청 대신 빌드 시 내장해 단일 파일 실행에서 상대 경로 요청이 발생하지 않도록 했다.
- `package.json`과 확장 매니페스트 버전이 다르면 빌드를 중단하며, CSP 해시가 포함된 HTML은 Git 줄바꿈 변환 대상에서 제외했다.
- 내부망·외부망·단일 HTML 산출물을 최신 소스와 검증 규칙으로 다시 생성했다.

### 주요 영향 파일

- `.gitattributes`
- `scripts/build-profile-config.mjs`
- `scripts/build-profile-config.d.mts`
- `scripts/build-single-html.mjs`
- `src/build-globals.d.ts`
- `src/pages/SettingsPage.tsx`
- `package.json`
- `dist/assets/app.js`
- `dist-web/planai.html`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `node scripts/build-extension.mjs --profile external`
- `node scripts/build-single-html.mjs`
- `npm run verify:single-html`
- 로컬 정적 서버에서 단일 HTML의 대시보드·설정 화면, 버전 `v1.2.0`, 콘솔 오류 없음 확인

### 주의사항

- 단일 HTML은 생성 후 문자열 치환이나 편집을 하면 CSP 무결성 검증에 실패하므로 반드시 소스를 수정한 뒤 다시 빌드해야 한다.
- `file://`에서 기본 UI를 여는 것과 AI API 호출 가능 여부는 별개다. 서버가 `Origin: null` 요청을 허용하지 않으면 AI 기능은 확장 프로그램 또는 허용된 HTTPS 배포 환경에서 사용해야 한다.
