# 업데이트 기록 운영 방법

프로젝트의 변경 사항은 Asia/Seoul 기준 날짜별 Markdown 파일에 누적한다.

## 파일 규칙

- 경로: `docs/updates/YYYY-MM-DD.md`
- 같은 날 여러 변경이 있으면 동일 파일 끝에 항목을 추가한다.
- 변경 이력 파일은 실제 변경과 같은 커밋에 포함한다.
- 비밀값과 개인정보는 마스킹 여부와 관계없이 기록하지 않는다.
- Git 추적 파일을 변경하지 않은 단순 검토·질문 응답은 생략할 수 있다.

## 항목 템플릿

```markdown
## HH:mm - 변경 제목

### 변경 요약

- 사용자 관점에서 달라진 동작
- 중요한 구현 또는 정책 변경

### 주요 영향 파일

- `src/example.ts`
- `dist/example.js`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm run build`

### 주의사항

- 보안, 호환성, 배포 또는 마이그레이션 관련 내용
```
