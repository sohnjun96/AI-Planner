## 22:56 - 내부망 HTTPS용 단일 HTML 빌드 추가

### 변경 요약

- JavaScript, CSS, 로고 아이콘을 모두 인라인으로 포함한 `dist-web/planai.html` 배포 파일을 추가했다.
- 단일 HTML은 승인된 내부망 LLM Endpoint만 포함하며, 외부 스크립트와 스타일을 허용하지 않는 해시 기반 CSP를 적용했다.
- Chrome 확장 프로그램이 아닌 안전한 HTTPS 환경에서도 API 키 자동 저장이 동작하도록 동일 출처 브라우저 저장소 호환 처리를 추가했다.
- 기존 확장 프로그램에서는 계속 `chrome.storage.local`을 우선 사용하고, 로고도 기존 외부 파일 경로를 유지하도록 빌드별 아이콘 주소를 분리했다.

### 주요 영향 파일

- `dist-web/planai.html`
- `scripts/build-single-html.mjs`
- `scripts/build-profile-config.mjs`
- `src/context/AppDataContext.tsx`
- `src/pages/SettingsPage.tsx`
- `src/components/AppShell.tsx`
- `src/build-globals.d.ts`
- `package.json`
- `dist/assets/app.js`

### 검증

- `npm run build:single-html`

- `npm run build:external`
- 로컬 정적 서버와 브라우저에서 대시보드, 해시 라우팅, 인라인 로고, AI 설정 화면 및 콘솔 오류 부재 확인

### 주의사항

- 운영 시 반드시 고정된 HTTPS 주소에서 제공하고 LLM 서버 CORS는 그 주소만 허용해야 한다. `Origin: null` 또는 와일드카드 허용은 금지한다.
- API 키는 해당 HTTPS 출처의 브라우저 저장소에 보관되므로, 배포 페이지에 제3자 스크립트를 추가하지 말고 서버에서도 CSP와 보안 헤더를 설정해야 한다.
- 확장 프로그램 백그라운드 알람과 도구 모음 실행 기능은 단일 HTML에 포함되지 않는다.
