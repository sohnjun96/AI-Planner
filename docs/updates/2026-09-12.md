## 13:29 - 나의 루틴 탭과 회차별 일정 제안 구현

### 변경 요약

- 대시보드 다음에 나의 루틴 탭을 추가했다. 반복 규칙 등록/수정/삭제, 검색, 전체·확인 필요·예정·일시 중지 필터와 처리 이력을 제공한다.
- 1~24개월 간격(매월·매년 포함), 시작 월, 예정일, 기본 시간, 0~30일 전 안내, 일정 생성 제안/알림만 받기를 설정할 수 있다.
- 대시보드에 확인 카드, 메뉴에 건수 배지를 표시한다. 초안 저장 시에만 일정과 회차를 한 트랜잭션으로 기록하여 중복 생성을 막는다. 초안 취소는 회차를 처리하지 않는다.
- 내일·3/7일 뒤·직접 날짜로 미루기, 이번 회차 건너뛰기, 알림 확인, 일시 중지·재개를 지원한다. 월말·윤년 보정과 장기 미접속 시 최근 회차 하나만 제안하는 계산을 적용했다.
- 확장 알림을 켜면 안내일 오전 9시에 기존 탭의 루틴 화면을 연다. 회차별 중복 표시 억제, 시작 시 예약 복구, 미루기/중지 시 예약 갱신을 처리하며 기존 일정 알림 동작은 유지한다.
- DB 스키마 v6에 routines/routineOccurrences를 추가하고 백업 v6에 포함했다. v4/v5 가져오기도 지원한다. 루틴에서 사용 중인 프로젝트·일정 종류 삭제를 차단한다.
- 모바일 내비게이션을 6개 항목에 맞추고 확장 번들·단일 HTML/ZIP을 갱신한다.

### 주의사항

- 데이터는 계속 로컬에만 저장한다. 확장 알림용 별도 저장 정보에는 루틴 제목/내용을 넣지 않고 회차 식별자와 시각만 전달한다.
- 새 백업은 v6이므로 루틴 기능이 포함된 앱에서 복원한다. v4/v5 백업으로 전체 복원하면 현재 루틴도 교체되어 빈 목록이 된다.
- 웹/단일 HTML에서는 앱을 열었을 때 및 사용 중 화면으로 안내한다. 확장 창 호출은 기존 설정의 창 표시 옵션을 따르며 브라우저가 실행 중이어야 한다.
- 루틴의 일정을 삭제해도 해당 회차 처리 기록을 유지하여 자동 재생성을 막는다. 루틴 자체를 삭제하면 처리 이력은 삭제하지만 이미 생성한 일정은 유지한다.
- 기존 작업 폴더 변경은 유지했다. 이번 요청에서는 버전 변경이나 커밋·푸시를 수행하지 않았다.
