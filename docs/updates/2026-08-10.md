# 2026-08-10 업데이트

## 23:09 - 라이브 중첩 목록 보존 및 노트 실행 취소 복구

### 변경 요약

- 라이브 편집에서 목록 항목에 Tab·Shift+Tab을 사용할 때 브라우저 기본 들여쓰기 대신 최대 4수준의 일관된 목록 깊이를 적용하도록 변경했다.
- 원문에서 불러온 중첩 목록과 라이브에서 변경한 목록 깊이를 Markdown 직렬화가 함께 인식하도록 하여 모드 전환 시 항목이 사라지거나 들여쓰기가 유실되지 않게 했다.
- 목록 항목에서 Enter로 다음 줄을 만들면 현재 목록 깊이가 이어지도록 보완했다.
- 노트 본문 편집 기록을 라이브·원문 모드 사이에 유지하고 `Ctrl+Z` 실행 취소와 `Ctrl+Shift+Z` 다시 실행을 지원한다.
- 연속 입력은 750ms 단위로 병합하고 실행 취소 기록은 최대 50단계·총 200만 자로 제한했다.

### 주요 영향 파일

- `src/components/LiveMarkdownEditor.tsx`
- `src/components/NoteEditor.tsx`
- `src/components/HelpModal.tsx`
- `src/utils/markdownEditing.ts`
- `tests/markdownEditing.test.ts`
- `dist/assets/app.js`
- `dist/assets/app.css`
- `dist-external/assets/app.js`
- `dist-external/assets/app.css`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- 브라우저에서 두 번째 목록 항목 Tab 들여쓰기 후 원문 전환 시 세 항목과 2수준 들여쓰기 보존을 확인
- 원문 모드에서 `Ctrl+Z`로 들여쓰기 이전 상태 복원, `Ctrl+Shift+Z`로 재적용을 확인
- 라이브 모드에서도 `Ctrl+Z`가 직전 목록 깊이 변경을 복원하는 것을 확인

### 보안·호환성 관련 주의사항

- 목록 깊이는 4수준으로 제한하고 브라우저 기본 DOM 변형에 의존하지 않아 비정상 중첩과 데이터 유실 가능성을 줄였다.
- 실행 취소 기록은 메모리 사용량과 단계 수를 제한하며 현재 선택된 노트 본문에만 적용된다.
- 외부 패키지, 네트워크 요청, 확장 권한을 추가하지 않았고 기존 Markdown 목록 저장 형식을 유지한다.

## 23:22 - 노트 자동 저장 시점 조정

### 변경 요약

- 입력이 멈춘 뒤 1초마다 노트를 저장하던 자동 저장 타이머를 제거해 일반 편집 중 버전이 계속 생성되지 않도록 했다.
- 미저장 초안은 다른 노트를 선택하거나 노트 페이지를 떠날 때 한 번만 자동 저장한다.
- 저장 버튼을 누른 경우와 AI 수정안을 적용한 경우에는 기존처럼 즉시 저장하고 버전을 생성한다.
- 도움말에 변경된 자동 저장 시점을 추가했다.

### 주요 영향 파일

- `src/pages/NotesPage.tsx`
- `src/components/HelpModal.tsx`
- `dist/assets/app.js`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- 브라우저에서 편집 중 자동 저장이 실행되지 않고 다른 노트로 전환할 때 저장되는지 확인

### 보안·호환성 관련 주의사항

- 전환·이탈 저장은 기존 IndexedDB 저장 경로만 사용하며 네트워크 요청이나 추가 권한을 사용하지 않는다.
- AI 수정 적용, 수동 저장, 체크리스트·메타데이터 변경의 즉시 저장 동작은 유지한다.
- 페이지 전환 전에 최신 초안을 ref로 보관해 오래된 상태가 저장되는 것을 방지한다.

## 23:27 - 노트 유휴 자동 저장 추가

### 변경 요약

- 노트의 마지막 수정 이후 15초 동안 추가 입력이 없으면 미저장 초안을 한 번 자동 저장하도록 했다.
- 입력이 이어지면 자동 저장 대기 시간을 다시 계산하며, 저장할 변경이 없으면 버전을 생성하지 않는다.
- 다른 노트나 페이지로 이동하거나 AI 수정·메타데이터·체크리스트 변경을 즉시 저장할 때는 대기 중인 타이머를 취소해 중복 저장을 방지한다.
- 도움말의 자동 저장 안내를 변경된 동작에 맞게 갱신했다.

### 주요 영향 파일

- `src/pages/NotesPage.tsx`
- `src/components/HelpModal.tsx`
- `dist/assets/app.js`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- 브라우저에서 입력 후 15초 전에는 저장되지 않고 15초 경과 후 한 번 저장되는지 확인

### 보안·호환성 관련 주의사항

- 자동 저장은 기존 IndexedDB 저장 경로만 사용하며 외부 통신이나 추가 권한을 사용하지 않는다.
- 타이머는 하나만 유지하고 입력·노트 전환·페이지 이탈 시 정리해 중복 실행과 불필요한 자원 점유를 방지한다.
- AI 수정 적용, 수동 저장, 노트·페이지 전환 저장 동작은 그대로 유지한다.
