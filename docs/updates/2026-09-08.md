## 06:45 - v1.3.0 기존 기능 빈틈 6건 보완

### 변경 요약

- 앱·확장 버전을 1.3.0으로 올리고 확장 번들 및 단일 HTML/ZIP을 재생성했다.
- 5MB 초과 외부 백업은 ZIP으로 압축하며 JSON/ZIP 복원을 지원한다. 압축 전 상한은 50MB이며 압축 해제 중에도 크기를 제한한다.
- 내부 자동 백업은 별도 IndexedDB에 최대 20개·합계 100MB를 보관한다. 기존 Chrome storage/localStorage 백업은 새 저장소에 기록·검증 후 이전하고, 자동 백업 실패는 토스트로 알린다. 전체 내보내기는 읽기 트랜잭션으로 일관된 스냅샷을 만든다.
- 프로젝트 삭제는 일정뿐 아니라 노트·세부 항목·AI 규칙 참조도 검사하고 연결 개수를 안내한다.
- 일정 삭제와 생성 실행 취소에서 노트 참조·연결 테이블을 함께 정리한다. 삭제 실행 취소는 연결도 복원하며 이후 노트 편집은 보존한다. 삭제와 직전 수정은 서로 다른 실행 취소 항목으로 남긴다.
- 기간 일정은 대시보드와 같은 날짜 범위 판정으로 브리핑에 포함하고 종료일 기준으로 지연을 분류한다.
- 알림 대상을 고를 때 과거 항목을 먼저 제외한 뒤 2,000개 제한을 적용한다.
- 끝과 시작이 같은 두 일정과 길이 0인 구간은 충돌로 표시하지 않는다.

### 주의사항

- JSON 백업 스키마는 v5를 유지하고 v4/v5 가져오기를 계속 지원한다. ZIP 및 5MB 초과 백업은 앱 v1.3.0 이상에서 복원한다.
- 별도 IndexedDB 백업도 브라우저 데이터 삭제 시 사라질 수 있으므로 외부 파일 백업은 계속 필요하다. 구버전 앱은 이전된 내부 백업 저장소를 읽지 못한다.
- 백업의 인증 정보 제거·참조 검증을 유지한다. ZIP은 backup.json 한 개만 허용하고 압축 해제 후 50MB 상한을 적용한다.
- 기존 빌드 설정·백업 알림 변경과 함께 Astra 브랜치의 1.3.0 커밋에 포함한다. 작업용 artifacts 및 이번 배포와 무관한 미추적 문서는 로컬에 유지한다.
