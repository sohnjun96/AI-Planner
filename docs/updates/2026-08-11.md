## 21:59 - 라이브 편집 마크다운 표식 삭제 보정

### 변경 요약

- 라이브 편집에서 제목 맨 앞의 `Backspace`가 이전 문단과 제목을 합치던 브라우저 기본 동작을 차단했다.
- 제목 표식을 한 번씩 지울 때 `H3 → H2 → H1 → 일반 문단` 순서로 전환해 본문과 문단 경계를 유지하도록 했다.
- 인용문 맨 앞에서도 `Backspace`로 `>` 표식만 해제하고 일반 문단으로 전환되도록 했다.
- 볼드·취소선·하이라이트 등 인라인 서식의 앞·뒤 경계에서 `Backspace`나 `Delete`를 누르면 주변 글자는 유지한 채 해당 마크다운 서식만 해제되도록 했다.
- 닫는 기호 바로 뒤처럼 커서가 서식 요소 바깥에 놓이는 경우에도 인접한 서식 경계를 찾아 정상적으로 해제한다.
- 라이브 편집에서 브라우저가 즉시 생성하는 `<b>`에도 `<strong>`과 같은 파란색 볼드 스타일과 `**` 표식을 적용해 모드 전환 없이 렌더링되도록 했다.

### 주요 영향 파일

- `src/components/LiveMarkdownEditor.tsx`
- `src/index.css`
- `dist/assets/app.js`
- `dist/assets/app.css`

### 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build:internal`
- `npm run build:external`
- Playwright 격리 브라우저에서 제목·인용 표식 삭제 후 문단 경계가 유지되는지 확인
- 볼드·취소선·하이라이트의 앞·뒤 안팎 경계와 기존 이탤릭·인라인 코드·링크의 닫는 경계에서 삭제 키를 눌러도 주변 글자 손실 없이 원문이 정확히 갱신되는지 확인
- 볼드 버튼 적용 직후 `<b>` 요소가 파란색과 양쪽 `**` 표식을 즉시 표시하고 원문에도 `**…**`가 동기화되는지 확인

### 주의사항

- `Ctrl`, `Meta`, `Alt` 조합의 삭제 키는 기존 브라우저·운영체제 단축키 동작을 유지한다.
- DOM 블록 태그 교체와 대상 인라인 서식 래퍼 해제만 수행하며 노트 텍스트와 저장 경로에는 별도 변환을 추가하지 않았다.
