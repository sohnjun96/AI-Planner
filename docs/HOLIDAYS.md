# 공휴일 데이터 관리

v1.4.0부터 대한민국 공휴일을 앱에 포함된 날짜 자료로 표시한다. 외부 API 호출, 사용자 설정, 데이터베이스 저장 또는 일정 생성은 하지 않는다.

## 범위와 표시

- 지원 범위: 2026년 1월 1일~2030년 12월 31일.
- 고정 공휴일, 설날·추석 연휴, 부처님오신날, 현행 규정에 따른 대체공휴일을 포함한다.
- 노동절·제헌절은 2026년에 시행된 공휴일 규정을 반영한다. 선거일과 임시공휴일은 공식 지정이 확인된 날짜만 포함한다.
- 월간 달력, 주간 날짜 제목, 일정이 있는 목록 날짜 제목, 선택일 제목에 휴일 이름을 표시한다. 좁은 월간 칸에서는 `휴일`로 축약하고 선택일 제목과 접근성 이름에는 전체 휴일명을 유지한다.
- 일정 필터와 무관하게 월간·주간의 공휴일 정보는 유지한다. 공휴일은 일정 건수·완료율·알림·지연·충돌 판정과 별개다.
- 지원 범위 밖 날짜를 임의로 계산하거나 평일로 확정하지 않는다. 해당 날짜는 추가 공휴일 배지 없이 기존 달력으로 표시한다.

## 자료 근거

자료 확인일은 2026-10-01이다. 2026·2027년은 공식 월력요항과 이후 시행된 규정을 함께 반영한다. 2028~2030년은 한국천문연구원의 음력 날짜와 현행 공휴일 규정으로 준비한 예정 자료이며, 해당 연도의 공식 발표와 추후 법령에 따라 달라질 수 있다.

## 앱 업데이트 시 갱신

1. `src/data/koreanHolidays.ts`의 날짜와 출처를 공식 월력요항·현행 규정으로 확인한다. 사전 자료는 확정 자료와 구분하고, 발표되지 않은 선거일·임시공휴일은 추측으로 추가하지 않는다.
2. 새 연도를 추가하면 데이터 범위, 이 문서와 날짜별 검증을 함께 갱신한다. 음력 변환은 빌드에 포함된 날짜 자료를 준비할 때만 사용하며 사용자 앱에서 외부 조회하지 않는다.
3. `npm test`, `npm run typecheck`, `npm run test:holidays`로 날짜·대체공휴일·월/주/목록 표시·집계 독립성을 검증한다. 브라우저 검사는 최신 단일 HTML 빌드 후 실행한다.
4. 앱 버전과 내부망·외부망 확장 및 단일 HTML·ZIP 산출물을 함께 갱신한다. 사용자 데이터 복원이나 데이터베이스 마이그레이션 없이 새 앱을 실행하면 갱신된 공휴일이 표시된다.
