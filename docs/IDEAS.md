# 제품 아이디어 노트

구현 우선순위를 확정하기 전, 사용자 경험에 도움이 될 수 있는 아이디어를 기록한다.
이 문서는 계획 메모이며, 여기에 적힌 기능은 아직 구현하지 않는다.

## 오늘 일정 전체 완료 축하

### 의도

하루에 남아 있던 일정이 모두 완료된 순간을 조용하지만 기분 좋게 기념한다.
업무를 더 많이 하도록 압박하기보다, 오늘 해낸 일을 알아봐 주는 경험을 만든다.

### 발동 조건

- 사용자가 상태를 변경한 직후
- 오늘 날짜의 활성 일정 중 `NOT_DONE` 또는 `ON_HOLD` 상태가 하나도 남아 있지 않을 때
- 취소된 일정은 완료 대상에서 제외한다.
- 같은 날에는 최초 1회만 표시한다. 이후 새 일정을 만들거나 기존 일정을 미완료로 되돌린 뒤 다시 모두 완료해도 반복 표시하지 않는다.

### 경험

1. 마지막 미완료 일정을 완료로 바꾼다.
2. 카드 주변에 짧고 가벼운 폭죽 또는 색종이 애니메이션을 표시한다.
3. 작은 메시지를 함께 표시한다.

   > 오늘 일정은 모두 마쳤어요. 수고했어요.

4. 2~3초 안에 자연스럽게 사라지며, 사용자 입력을 막지 않는다.

### 디자인 원칙

- 과도한 게임화, 점수, 연속 출석, 실패 벌점은 사용하지 않는다.
- 업무 앱의 차분한 분위기에 맞춰 1회성의 절제된 모션을 사용한다.
- `prefers-reduced-motion` 환경에서는 애니메이션 대신 정적인 축하 배너만 표시한다.
- 일정이 전혀 없는 날에는 발동하지 않는다.
- 축하는 사용자 기기 로컬 상태로 당일 1회만 기억한다.

### 구현 메모

- 대시보드의 일정 상태 변경 경로를 공통으로 감지한다.
- 당일의 일정 집계는 기존 상태 유틸리티와 날짜 키를 사용한다.
- 축하 UI는 전역 오버레이 또는 대시보드 상단 토스트 형태를 검토한다.
- 완료 시점과 표시 여부는 `localStorage` 또는 설정 저장소에 날짜 키 기준으로 보관한다.
