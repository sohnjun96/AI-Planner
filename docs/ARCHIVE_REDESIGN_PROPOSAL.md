# 일정아이 기록 탭 재설계 제안

> 방향: **끝난 일을 쌓아두는 곳**이 아니라, 바쁜 날들 사이에서 **내가 지나온 업무 장면을 기분 좋게 다시 보는 곳**으로 바꾼다.

## 한 줄 요약

보관함의 새 이름은 **기록**이다. 일정과 노트를 생산성 자료로 재활용하라고 재촉하지 않는다. 대신 완료된 일정, 당시의 노트, 프로젝트의 작은 변화가 한 장면으로 이어져서 “그때 내가 이런 일을 해냈구나”를 느끼게 하는 **업무 앨범**으로 만든다.

## 왜 새로 설계해야 하는가

단순 보관함은 다시 들어갈 이유가 약하다. 오래된 일정과 노트가 날짜순으로 쌓이면, 필요한 순간에 검색하는 저장소가 될 뿐이다.

사무용 앱에서 과거 기록은 더 실용적이어야 한다는 부담도 크다. 하지만 사용자가 퇴근 전이나 지친 오후에 다시 보고 싶은 것은 “다음번에 더 잘하는 법”보다 다음과 같은 감각이다.

- 오늘도 생각보다 많은 일을 해냈다는 안도감
- 한 회의와 한 메모가 어디까지 이어졌는지 보는 재미
- 반복되는 일상 속에서도 프로젝트가 조금씩 움직였다는 감각

기록 탭은 사용자를 평가하거나 복기시키지 않는다. **나의 업무 시간을 다정하게 전시하는 공간**이어야 한다.

---

## 새 탭의 이름과 역할

### 탭 이름: `기록`

사이드바에서는 `보관함` 대신 `기록`으로 표시한다. 보조 문구는 “지나온 업무의 장면들”처럼 짧고 감성적으로 둔다.

### 이 탭이 답해야 하는 질문

1. **그날 나는 어떤 하루를 보냈지?**
2. **이 프로젝트는 어떤 장면들을 지나왔지?**
3. **내가 최근에 해낸 일 중, 다시 보면 기분 좋은 것은 무엇이지?**

`다음 할 일`, `체크리스트 재사용`, `반복 업무 개선` 같은 기능은 기록 탭의 목적에서 제외한다. 필요하면 대시보드나 AI 일정 기능에서 다룬다.

---

## 핵심 경험: “완료 → 장면 → 기억”

```text
일정 완료
  → 그날의 노트·프로젝트·사진 같은 맥락을 조용히 연결
  → AI가 사실 중심의 짧은 한 줄 제목을 제안
  → 사용자는 원하면 저장, 아니면 아무것도 하지 않음
  → 나중에 그날의 한 장면으로 다시 만남
```

AI는 일의 효율을 평가하지 않는다. 완료된 일정과 사용자가 작성한 노트에서 **무엇을 했는지, 무엇이 남았는지**만 짧고 사실적으로 묶는다. AI 요약은 선택 사항이며, 사용자가 저장하지 않아도 일정 완료 경험은 그대로 끝난다.

---

## 화면 구성

### 1. `이런 날도 있었어요` — 기록 탭의 첫 화면

매번 오늘의 기록만 보여주지 않고, 과거의 한 장면을 부드럽게 꺼내 준다.

```text
2026년 6월 3일 수요일
선행기술조사 업체 방문 결과를 정리한 날

회의 2개 · 노트 1개 · 완료한 일정 4개
“소규모 업체와의 논의에서 예산 쟁점을 정리했어요.”

[그날 다시 보기]
```

카드는 날짜, 프로젝트 색, 당시 완료한 일정 수를 활용하되 숫자를 성과 지표처럼 크게 보이지 않는다. 사용자는 카드를 열어 그날의 일정 흐름과 연결된 노트를 타임라인처럼 본다.

### 2. `오늘의 마침표`

하루의 일정이 모두 완료되었거나 사용자가 원할 때만 열린다. “오늘을 기록해야 한다”는 숙제가 아니라, 하루를 닫는 작은 선택이다.

```text
7월 12일 일요일
오늘의 마침표

오전에는 발표 자료를 정리했고,
오후에는 회의 일정과 장소를 확정했어요.

오늘 남기기:  [한 줄 저장] [그냥 닫기]
```

저장한 문장은 일기의 형태가 아니라 그날 카드의 작은 캡션이 된다. 사용자가 직접 한 줄을 적으면 AI 문장보다 항상 우선한다. 기록하지 않은 날은 빈칸이나 실패로 표현하지 않는다.

### 3. `업무 앨범`

달력이나 세로 타임라인으로 과거를 탐색한다. 일정이 많은 날은 카드가 조금 더 풍성해지고, 노트가 연결된 날에는 작은 메모 표식을 붙인다.

각 날짜를 열면 다음을 한 화면에서 보여준다.

- 그날 완료한 일정의 제목과 시간 흐름
- 당시 작성하거나 연결한 노트의 제목
- 프로젝트 색과 종류
- 사용자가 남긴 한 줄 또는 AI가 만든 사실 요약

정보를 전부 펼치지 않는다. 첫 화면은 **한 장의 하루 카드**처럼 보여 주고, 더 보고 싶을 때만 일정·노트 원문으로 들어간다.

### 4. `프로젝트의 장면들`

프로젝트는 진행률 막대가 아니라 작은 전시처럼 다룬다.

```text
특허심사 AI

6월 3일  · 업체 방문 결과를 정리함
6월 7일  · 핵심 쟁점을 노트로 남김
6월 12일 · 발표 자료를 완성함
```

각 장면에는 그때 완료한 일정과 노트가 붙는다. 프로젝트가 끝나면 “완료”로 사라지는 대신, **이 프로젝트가 지나온 장면들**을 한 장의 이야기로 볼 수 있다. 업무 성과를 긴 보고서로 만들지 않고, 제목과 한 줄 정도로만 연결한다.

### 5. `기억에 남기기`

사용자가 특별히 마음에 드는 날·노트·프로젝트 장면을 별표로 남길 수 있다. 이 영역은 중요한 업무 자료 보관함이 아니라, “나중에 다시 보면 좋은 순간”을 모으는 개인 컬렉션이다.

- 힘들었던 프로젝트를 마무리한 날
- 발표나 회의를 잘 끝낸 날
- 기억해 두고 싶은 한 줄이 있는 노트
- 동료와 함께 성과를 낸 일정 묶음

별표를 남기는 일은 검색성과 무관하다. 기록에 정을 붙이는 장치다.

## AI 일정과의 연결

### 일정 완료 시: 결과를 자동으로 만들지 않고, 장면의 재료로만 쌓기

완료된 일정은 그날 카드에 자연스럽게 들어간다. AI가 개입해야 할 때도 아주 작게 제안한다.

> “오늘 일정에서 한 줄을 남겨볼까요?”

- `AI 한 줄 보기` — 완료 내용과 연결 노트에서 한 문장만 생성
- `직접 쓰기` — 사용자가 한 줄 캡션 작성
- `이번에는 닫기` — 아무 기록도 요구하지 않음

AI는 새 일정, 후속 업무, 체크리스트를 제안하지 않는다. 기록 흐름 안에서는 사용자의 하루를 **마무리하는 역할**에만 집중한다.

### AI 일정 초안은 ‘과거의 장면’으로 남기기

AI와 대화해 만든 일정 초안도, 최종적으로 확정·완료된 경우에만 기록의 일부가 된다. 그날 카드에는 “AI와 정리한 일정” 같은 작은 표시를 두어, 사용자가 어떤 도움을 받아 일을 정리했는지 기억할 수 있게 한다.

미확정 초안이나 취소된 제안은 기록 탭에 억지로 남기지 않는다.

---

## 노트와의 연결

### 노트를 그날의 분위기로 연결하기

노트는 독립적인 문서로 남되, 작성일 또는 사용자가 연결한 일정 기준으로 그날 카드에 작은 조각처럼 붙는다.

```text
7월 12일의 장면

완료한 일정
• 발표 자료 준비
• 회의 일정 및 장소 공지

그날 남긴 노트
• 선행기술조사 업체 방문 결과
```

노트 원문을 AI가 재해석하거나 ‘지식 카드’로 바꾸지 않는다. 사용자가 열면 기존 노트 화면으로 이동하며, 기록 탭에서는 제목과 짧은 발췌만 보여 준다.

### 노트에서 기억에 남기기

노트 메뉴에 `기억에 남기기`만 추가한다. 선택한 노트는 별표 컬렉션과 관련 날짜 카드에 표시된다. 사용자가 직접 고른 문서만 눈에 띄게 보이므로, AI가 중요도를 단정하지 않는다.

---

## 감정적 보상: 조용하지만 분명하게

직장인을 위한 보상은 경쟁이나 습관 압박보다, **마무리를 알아봐 주는 반응**이 적합하다.

- **오늘 일정 모두 완료**: 작은 폭죽 또는 은은한 반짝임과 함께 “오늘 계획한 일을 모두 마쳤어요.”
- **기록 카드 열기**: 그날의 프로젝트 색이 천천히 드러나며, 성과 수치보다 한 줄 캡션이 먼저 보임
- **프로젝트 장면 완성**: “이 프로젝트에 12개의 장면이 남았어요.”처럼, 수고의 시간을 부드럽게 알려 줌
- **과거의 오늘**: 작년·지난달의 같은 날짜에 남긴 장면이 있을 때만 조용히 노출

피해야 할 요소:

- 연속 접속일, 순위, 다른 사용자 비교
- 기록하지 않은 날을 실패처럼 보이게 하는 빈 상태
- 완료 수만 크게 보여 주는 생산성 게임화
- “다음에는 이렇게 하세요”처럼 업무를 평가하는 AI 문장

## AI 동작 원칙

| 원칙 | 동작 |
| --- | --- |
| 선택한 정보만 사용 | 해당 날짜의 완료 일정과 연결·선택한 노트만 재료로 사용 |
| 사실을 먼저 보여주기 | 추측·평가 없이 제목, 완료 내용, 결정된 사실 위주로 요약 |
| 먼저 초안, 나중에 저장 | AI 문장과 별표는 자동 저장하지 않음 |
| 짧고 조용하게 | 한 줄 제목 또는 두 문장 이하만 제안 |
| 언제든 닫기 | 기록 제안을 닫아도 다시 요구하지 않음 |
| 원문으로 돌아가기 | 모든 장면에서 원래 일정과 노트를 열 수 있음 |

## 첫 출시 범위

### 1단계 — ‘지난 하루’가 보이게 하기

- 탭 이름을 `기록`으로 변경
- 날짜별 완료 일정과 연결 노트를 묶은 하루 카드
- 기록 탭 상단의 과거 장면 추천 카드
- 일정 완료 뒤 `한 줄 저장` 또는 `닫기`

### 2단계 — 앨범처럼 둘러보기

- 월별 달력·타임라인 탐색
- 프로젝트별 장면 타임라인
- 노트 메뉴의 `기억에 남기기`
- 별표 컬렉션

### 3단계 — 감성적 마무리 다듬기

- 모든 일정 완료 시 폭죽·반짝임
- 과거의 오늘 카드
- 프로젝트 장면을 한 장으로 공유하거나 이미지로 저장하는 기능

---

## 성공 기준

이 탭이 성공했다는 신호는 사용자가 과거 기록을 업무 자료로 재활용하는 횟수가 아니다.

- 사용자가 목적 없이도 기록 탭을 가끔 둘러보는가
- 하루 카드에서 일정과 노트의 연결을 자연스럽게 이해하는가
- 사용자가 스스로 기억에 남길 날과 노트를 별표로 남기는가
- 프로젝트를 마친 뒤 기록을 보며 “여기까지 왔구나”를 느끼는가
- 사용자가 기록하지 않은 날에도 부담이나 죄책감을 느끼지 않는가

## 최종 제안

`기록`은 끝난 일을 다음 행동으로 바꾸는 곳이 아니다. **바쁘게 지나온 업무 시간을 한 장면씩 돌려보며, 내가 해낸 일을 알아차리는 업무 앨범**이어야 한다. 일정아이의 AI는 사용자를 더 바쁘게 만드는 조력자가 아니라, 지나온 하루를 짧고 따뜻하게 비춰 주는 역할을 맡는다.
